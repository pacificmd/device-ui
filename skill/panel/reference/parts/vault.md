# Vault

More from `device-ui/vault`, with what the source says about them.

## `d-vault`

A vault: the round door, as `d-vault="door"`.

Forms: `door`.

### `[d-vault~="door"]`

The door in its frame. `open` runs from 0, bolts home, to 1, bolts drawn in.

Import `device-ui/vault`. Write `<div d-vault="door">`.

| Attribute | Does | Default |
| --- | --- | --- |
| open | 0 is bolts home, 1 is bolts drawn in. Numbers between work. | 0 |
| d-vault | The form, then any option words. |  |
